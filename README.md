# Music_Finder_App_Langchain
A multilingual AI Music Finder built with Streamlit and LangChain that lets users search for songs by singing/humming or by uploading an image of an actor to discover their debut songs.


# LangChain Music Finder

1. Install requirements: `pip install -r requirements.txt`
2. Run app: `streamlit run app.py`
3. Enter OpenAI API Key in the sidebar.

This project is beginner friendly and easy to understand and deploy.
